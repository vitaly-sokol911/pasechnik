# Пасека Вячеслава

Одностраничный сайт пасеки: каталог пчелопродукции, разбор цены, доставка
и приём заявок.

## Технически

Без сборщиков, фреймворков и зависимостей — весь сайт в одном файле:
разметка, стили и скрипты. Открывается двойным кликом, публикуется как есть.

| | |
|---|---|
| Вес страницы | ~91 КБ |
| Внешние зависимости | шрифты Google, фотографии Unsplash |
| Поддержка | десктоп, планшет, телефон от 375 px |
| Скорость | отдаётся меньше чем за секунду |

Шрифты — антиква Prata для заголовков и Manrope для текста. Палитра и
отступы вынесены в CSS-переменные, оформление меняется правкой в одном месте.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | сайт целиком |
| `politika.html` | политика обработки персональных данных |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

Восемь блоков: каталог из семи позиций, разбор цены, история пасеки,
гарантии, отзывы, вопросы, доставка, форма заявки. Фирменный элемент —
«Паспорт партии» с данными лабораторного анализа на первом экране.

## Интерфейс

- окно переписки в оформлении мессенджера: отправка, отметки о доставке,
  статус собеседника;
- форма с проверкой заполнения и подтверждением на месте;
- раскрывающиеся вопросы на `<details>` — работают и без JavaScript;
- появление блоков при прокрутке через `IntersectionObserver`
  с запасным вариантом, если наблюдатель недоступен.

## Доступность

Видимый фокус при работе с клавиатуры, подписи ко всем изображениям,
объявление подтверждений для экранных дикторов через `role="status"`,
модальное окно с `aria-modal` и закрытием по Esc, уважение к отключённой
анимации (`prefers-reduced-motion`).

## Безопасность

| Что закрыто | Как |
|---|---|
| Источники загрузки ресурсов | мета-тег `Content-Security-Policy` |
| Встраивание в чужой фрейм | скрипт в `<head>`, выход на верхний уровень |
| Утечка адреса при переходах | мета-тег `referrer` |
| Подмена окна по внешним ссылкам | `rel="noopener"` на всех ссылках |
| Выполнение кода из пользовательского ввода | вставка через `createTextNode` |

В коде нет `innerHTML`, `eval`, `document.write`, обработчиков событий
в разметке и обращений к сети.

GitHub Pages не позволяет задавать свои HTTP-заголовки, поэтому защита
живёт внутри страниц. Настройки для Apache и Netlify лежат в истории git.
