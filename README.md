# Пасека Вячеслава — лендинг

Демонстрационный сайт-визитка для портфолио: пасека, продажа мёда и пчелопродукции.

**Живая версия:** https://pasechnik.netlify.app (переезжает на GitHub Pages)

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | весь сайт — разметка, стили и скрипты в одном файле |
| `politika.html` | политика обработки персональных данных |
| `_headers` | заголовки безопасности (**работают только на Netlify и Cloudflare Pages**) |

Без сборки и зависимостей: открывается двойным кликом, публикуется перетаскиванием папки.

## Что внутри

Восемь блоков: каталог из семи позиций, разбор цены, история пасеки, гарантии,
отзывы, вопросы, доставка и заявка. Фирменный элемент — «Паспорт партии»
с данными лабораторного анализа на первом экране.

## Важно про демо-режим

Сайт ничего никуда не отправляет — это витрина работы, а не рабочий магазин:

- форма заявки показывает подтверждение, но данные остаются в браузере;
- кнопки WhatsApp и Telegram открывают окно переписки прямо на сайте,
  сообщение получает отметку о доставке и никуда не уходит;
- страница закрыта от индексации (`noindex, nofollow`).

## Заголовки безопасности

`_headers` — формат Netlify. **GitHub Pages его игнорирует** и не позволяет
задавать свои HTTP-заголовки вообще. На GitHub Pages продолжают работать только
те правила, что прописаны мета-тегами внутри `index.html`: политика безопасности
контента, политика источника перехода и запрет индексации.

Теряются при переезде: запрет встраивания во фрейм, запрет угадывания типа файла
и отключение браузерных разрешений. Для демо-сайта без данных и платежей это
некритично, но знать стоит.

Файл оставлен в репозитории: он снова заработает, если вернуться на Netlify
или перейти на Cloudflare Pages.
