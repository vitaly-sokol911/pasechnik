# Пасека Вячеслава — лендинг

Демонстрационный сайт-визитка для портфолио: пасека, продажа мёда и пчелопродукции.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | весь сайт — разметка, стили и скрипты в одном файле |
| `politika.html` | политика обработки персональных данных |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

Без сборки и зависимостей: открывается двойным кликом, публикуется как есть.

## Что внутри

Восемь блоков: каталог из семи позиций, разбор цены, история пасеки, гарантии,
отзывы, вопросы, доставка и заявка. Фирменный элемент — «Паспорт партии»
с данными лабораторного анализа на первом экране.

## Демо-режим

Сайт ничего никуда не отправляет — это витрина работы, а не рабочий магазин:

- форма заявки показывает подтверждение, но данные остаются в браузере;
- кнопки WhatsApp и Telegram открывают окно переписки прямо на сайте,
  сообщение получает отметку о доставке и никуда не уходит;
- страница закрыта от индексации (`noindex, nofollow`), чтобы не появляться
  в поиске как настоящий магазин мёда.

## Защита

GitHub Pages не позволяет задавать свои HTTP-заголовки, поэтому вся защита
живёт внутри самих страниц:

| Что защищает | Как сделано |
|---|---|
| Откуда можно грузить ресурсы | мета-тег `Content-Security-Policy` |
| Встраивание в чужой фрейм | скрипт в `<head>`: страница выходит наверх |
| Утечка адреса при переходах | мета-тег `referrer` |
| Индексация поисковиками | мета-тег `robots` |
| Шифрование канала | HTTPS от GitHub Pages, включить «Enforce HTTPS» |

Пользовательский ввод в чате вставляется через `createTextNode`, поэтому
разметка и скрипты из сообщений не выполняются. Внешних запросов,
`innerHTML`, `eval` и открытия окон в коде нет.

Заголовки `X-Content-Type-Options` и `Permissions-Policy` на GitHub Pages
недостижимы. Для сайта без загрузки файлов и без доступа к камере,
микрофону и геолокации это не создаёт уязвимости.

Настройки для других хостингов (`_headers` для Netlify, `.htaccess` для
Apache) лежат в истории git — если проект переедет, их можно вернуть
командой `git log --diff-filter=D --name-only`.
